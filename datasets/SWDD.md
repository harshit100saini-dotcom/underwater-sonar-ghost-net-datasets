# SWDD / Sonar Wall & Anomaly Detection

Candidate source for annotated side-scan sonar anomaly/man-made-structure data.

## Intended use

Useful as supplementary data for learning sonar anomalies and man-made structures. It should not be assumed to represent ghost nets directly.
