# OpenSonarDatasets

Official source: https://github.com/remaro-network/OpenSonarDatasets

Purpose: curated directory of open underwater sonar datasets, including side-scan sonar (SSS), forward-looking sonar (FLS), and multibeam sources.

Use this repository as the first discovery point. Before downloading or redistributing any dataset, verify the individual dataset's license, access requirements, annotation format, and sonar modality.

## Planned metadata

- Dataset name
- Official URL
- Sonar modality
- Number of images / sequences
- Resolution
- Annotation format
- Object classes
- License
- Download method
- Ghost-net relevance
